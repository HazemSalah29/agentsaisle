# Third-party software (video library)

The video skills **bundle none of the programs below** (one small library, Shiki, is vendored as source; see the last section). They run programs the user installs, and our scripts never download or install anything. Licences are as recorded on 2026-11-01; `TODO(verify)` each before a public release.

| Program                     | Version tested                  | Licence                             | How it is used                                                                                                                                                                                                                         |
| --------------------------- | ------------------------------- | ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HyperFrames (HeyGen)        | 0.8.226                         | Apache 2.0                          | Renders the generated HTML project to frames; user-installed (`npm install --global hyperframes@0.8.226`).                                                                                                                             |
| FFmpeg / ffprobe            | 9.0.2                           | LGPL or GPL, depending on the build | Mixes audio, writes the final MP4, measures audio. System install.                                                                                                                                                                     |
| Chromium (via HyperFrames)  | whatever HyperFrames fetches    | BSD-style (Chromium)                | Headless rendering, managed by HyperFrames.                                                                                                                                                                                            |
| Node.js                     | 22+                             | MIT                                 | Runs our scripts.                                                                                                                                                                                                                      |
| playwright-core (Microsoft) | not pinned yet (`TODO(verify)`) | Apache 2.0 (`TODO(verify)`)         | Optional. Drives a headless Chromium for `/video-showcase` screen capture; only `capture.mjs` imports it. Installed by the user with `npm install --prefix ~/.aisle-video playwright-core`; never bundled or installed by our scripts. |
