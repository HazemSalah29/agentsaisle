# Third-party software (video library)

The video skills **bundle none of the programs below** (two libraries, Shiki and three.js, are vendored as source; see the last section). They run programs the user installs, and our scripts never download or install anything. Licences are as recorded on 2026-11-01; `TODO(verify)` each before a public release.

## Fonts shipped with the library

| Font  | Licence                         | Size   | Where                                       | Why                                                                                 |
| ----- | ------------------------------- | ------ | ------------------------------------------- | ----------------------------------------------------------------------------------- |
| Anton | SIL Open Font License 1.1 (OFL) | 167 KB | `video-core/assets/fonts/` (with `OFL.txt`) | The heavy condensed display font of the `kinetic` scene (speech-synced bold words). |

Anton is by The Anton Project Authors (Copyright 2020, https://github.com/googlefonts/AntonFont). It was copied once from the google/fonts repository (`ofl/anton/`) with its licence text; nothing downloads it at run time, it is not modified, and it is copied into a project's render folder only when a `kinetic` scene exists. The OFL lets it be bundled and used in videos (including commercial ones) as long as the licence text travels with the font and the font is not sold on its own.
