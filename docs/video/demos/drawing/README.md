# Drawing demo (synthetic)

The "drawing" here is a SYNTHETIC picture made by `registry/skill-tests/fixtures/make-drawing.py`, not a child's art. The files show each step of `/video drawing`: `trace-sheet.svg` (what the tracer found), `marks.json` (which regions are which; auto-guessed and unedited), `bible.md` (filled in by hand), `puppet.json` (the rig) and `sheet.svg` (the character with every mouth shape).

No original image is kept here; a real drawing would stay in `characters/<name>/private/`. No MP4 has been rendered yet.
