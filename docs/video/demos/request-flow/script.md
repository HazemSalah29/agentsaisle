# What aisle add does

[l1] This is what aisle add does, read from its own code.
  beat: hook
  on-screen: aisle add, step by step

[l2] You might think it just copies a folder.
  beat: misconception

[l3] It is closer to a careful delivery: look up, fetch, inspect, shelve.
  beat: analogy

[l4] First, the command asks the registry site for the skill list.
  beat: step
  fact: f1

[l5] Back come the versions, and a pinned commit for each.
  beat: step
  fact: f2

[l6] Then it asks GitHub for that exact commit.
  beat: step
  fact: f3

[l7] What comes back is a tarball. Nothing is cloned.
  beat: step
  fact: f3

[l8] Before anything is installed, the audit engine reads the files.
  beat: step
  fact: f5

[l9] It sends back a grade and a list of findings.
  beat: step
  fact: f5

[l10] Only then is the folder moved in, and the lockfile updated.
  beat: step
  fact: f6

[l11] A critical finding blocks the install, unless you force it and type the name.
  beat: edge
  fact: f7

[l12] Downloaded, checked, never run.
  beat: takeaway
  fact: f4
