# Edit

Improve the text; keep the author's meaning and voice.

1. Read the whole piece first and note its audience and purpose in one line.
2. Fix errors: spelling, grammar, punctuation, inconsistent names and numbers.
3. Cut: filler words, repeated points, throat-clearing openings. Prefer the shorter phrase when meaning is equal.
4. Clarify: replace vague words with specific ones, turn passive sentences active where it reads better, split sentences that carry more than one idea.
5. Keep the author's terms, tone and formatting conventions. Do not add claims, facts or opinions that are not in the text.
6. Return the edited text, then a short list of the changes that matter, and flag any sentence you could not fix without asking the author.

Show changes the user can accept or reject; never silently rewrite an argument.
