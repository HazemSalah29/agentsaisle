# Style recipes

**A style is a look, not a set of props.** It is the material, palette, texture, light and motion. Any object, place or scene can be drawn in any style, and any topic can use any style. The props in each recipe and working example are examples only, and the uses below are ideas, never limits.

A menu to use, mix or ignore per story (Workflow step 3). Each recipe links a working 10 s page in `assets/styles/<slug>.html`. For some recipes the full source prompt, with the reference animation's code, is in `references/prompt-<id>.md`; the recipe's References names it.
