# Carousel templates

A template keeps the look of a carousel: the colours, fonts, size and style. It never keeps the words, so each new carousel gets its own text.

## Rules

- One file per template, named in lowercase words with hyphens, for example `calm-dark.md`.

- Claude saves a template when you say "save this as a template" after a carousel.

- To use one, say "use my calm-dark template" or run `/video reel carousel calm-dark`.

- To drop a template, delete its file.
