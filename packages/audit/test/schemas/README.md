# Vendored schema (tests only)

`sarif-schema-2.1.0.json` is the OASIS SARIF 2.1.0 JSON Schema, copied unmodified from
https://github.com/oasis-tcs/sarif-spec (`sarif-2.1/schema/`) on 2026-10-24. It is used only by
`test/formats.test.ts` to validate our SARIF output. It is not part of the published package.
